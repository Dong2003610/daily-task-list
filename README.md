# 每日任务清单 (Daily Task List)

一个部署在 GitHub Pages 上的**每日工作任务清单** Web 应用。

在线访问：**https://dong2003610.github.io/daily-task-list/**

## 功能特性

- ✅ 今日任务 / 历史任务双视图，历史任务按日期分组降序排列
- ⏱️ 任务计时器（正计时 / 倒计时），支持切换进行中的任务
- 🔔 定时任务提醒（全屏弹窗 + 提示音，解决浏览器自动播放限制）
- 📅 按日期筛选与归档
- 🔐 登录页 + 共享账号自动登录，实现任务持久化与跨设备同步
- 📊 任务完成进度统计

## 技术栈

React · TypeScript · Vite · Tailwind CSS

## 部署

构建产物直接部署在 GitHub Pages（main 分支根目录）。

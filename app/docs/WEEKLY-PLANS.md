# 周计划功能 · 2026-10-13

采用“周目标常驻侧栏 + 每日执行清单”的信息结构。周一会议确定一周的总目标，每天选择其中需要推进的事项安排到今日。周目标不等同于一次每日任务，完成进度独立确认。

桌面端右侧周计划跟随滚动，列表高度受限、可独立滚动；短窗口侧栏可滚动以访问计时器。手机端位于每日任务上方，向下浏览时显示紧凑的顶部入口，点击返回周计划。保持现有专注计时浮动栏。

周期统一使用北京时间周一至周日，支持历史复盘和下周预排。周一自动切换仅作用于正在查看本周的界面；手动选择的历史周仍保留。旧周未完成目标不会自动复制，以便周会重新评估。当前属于个人账号计划，不提供团队共享或成员分配。

## 上线条件

1. 在 Supabase SQL Editor 执行 `supabase/migrations/20261013_add_weekly_tasks.sql`。
2. 确认成功创建表，再发布 `dist/` 和源码。
3. 验证本人可以新增和读取周计划，其他账号无法读写其记录。

使用独立 `weekly_tasks` 表和 owner RLS；每条记录按周一日期分区查询。创建及安排使用稳定 ID，失败重试不覆盖现有记录。并发编辑同一条目标采用最后保存。每日任务依旧使用原表。

JSON 完整备份升级为 v3，增加 weeklyTasks，包含全部历史周目标；CSV 继续导出每日任务。周计划获取失败时拒绝生成残缺完整备份。接口未准备好时在周计划卡片局部显示错误，每日工作不受阻。
